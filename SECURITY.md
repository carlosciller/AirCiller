# Seguridad y privacidad

## Informar de un problema

Este repositorio no dispone todavía de un canal privado de seguridad. Antes de publicarlo, configura en GitHub la opción **Private vulnerability reporting**. Hasta entonces, no abras una incidencia pública que revele una credencial, una dirección de red privada o datos personales.

## Datos que no deben adjuntarse

- Códigos de emparejamiento o credenciales AirPlay.
- Exportaciones del Llavero.
- Nombres y direcciones de dispositivos de la red doméstica.
- Rutas completas con nombres de usuario o títulos de archivos privados.
- Películas, audios o subtítulos sujetos a derechos de terceros.

Los registros deben revisarse y anonimizarse antes de compartirlos. Si una credencial pudiera haberse expuesto, elimínala del Llavero y vuelve a autorizar el Apple TV.
