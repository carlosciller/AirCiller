# AirCiller 0.12.0

This update adds optional subtitle search and makes long playback sessions more reliable.

### New

- Find subtitles on OpenSubtitles.com when you ask, review the available matches, and choose the file to download.
- Keep optional OpenSubtitles credentials securely in the macOS Keychain.

### Improvements

- Separates audio track selection from output format.
- Keeps original audio as the default whenever Apple TV can play it.
- Labels E-AC-3 5.1 and AAC stereo clearly as optional audio conversions.

### Fixes

- Prevents repeated seeking and range changes from exhausting local playback resources during long movies.
- Stops a failed local stream with a useful message instead of leaving Apple TV loading indefinitely.
- Cancels helper processes promptly when playback or authorization work is stopped.
- Clears temporary seeking and buffering messages when playback resumes.
- Shows the correct SRT label when OpenSubtitles omits a filename extension.

### Privacy

- OpenSubtitles searches start only when requested. AirCiller never uploads the movie.
