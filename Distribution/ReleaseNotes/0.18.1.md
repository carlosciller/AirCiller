# AirCiller 0.18.1

AirCiller takes up about 7.5 MB less space by removing unused Python package
installers. Playback dependencies remain included, so no additional setup or
downloads are needed.

The build installer has also been updated and its download is verified before
use. Playback formats and requirements are unchanged.

[Maintenance and validation record](https://github.com/carlosciller/AirCiller/blob/v0.18.1/Docs/BUILD_PIP_MAINTENANCE.md).
