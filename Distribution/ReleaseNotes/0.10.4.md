# AirCiller 0.10.4

This release adds simpler setup, better track preferences, and a cleaner playback session.

### New

- Download verified FFmpeg and AirPlay components from AirCiller, with visible progress, cancellation, and rollback.
- Choose standard, SDH, or forced subtitles for the preferred language.
- Export a private local diagnostic report and reset authorization for the selected Apple TV.

### Improvements

- Keeps Playlist and Recents rows aligned when filenames wrap.
- Retains Homebrew and MacPorts components as manual alternatives.

### Fixes

- Chooses the movie video stream instead of embedded cover art.
- Stops media analysis promptly when playback is stopped or another movie is selected.
- Stops the Mac playback session when Apple TV closes it, without a ghost timer or false connection error.
