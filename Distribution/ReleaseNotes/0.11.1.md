# AirCiller 0.11.1

This update improves AirPlay reliability when authorization or network conditions change.

### Fixes

- Prevents overlapping Apple TV authorization attempts that could trigger repeated code prompts.
- Keeps the selected Apple TV identified correctly across IPv4, IPv6, VPNs and multiple network adapters.
- Keeps playback confirmation and stream measurements tied to the active Apple TV session.

### Reliability

- Validated natural movie completion, automatic Playlist advance, rapid remote commands and clean stopping on a physical Apple TV.
