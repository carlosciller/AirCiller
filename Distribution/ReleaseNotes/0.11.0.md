# AirCiller 0.11.0

AirCiller now includes its complete tested playback engine.

### Improvements

- Works without installing or maintaining FFmpeg, Python, or AirPlay components separately.
- Keeps the engine versions available in a compact section under Diagnostics.
- Updates the playback engine only as part of a tested AirCiller release.

### Reliability

- Uses the FFmpeg and AirPlay versions shipped with the app for every playback route.
- Reports an incomplete installation instead of silently switching to an external engine.
- Verifies the pinned engine archives, executable versions, and licenses during the build.

The download is larger because the complete engine is included. Playback behavior, original-file protection, and the confirmation required for audio conversion remain unchanged.
