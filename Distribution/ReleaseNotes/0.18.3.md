# AirCiller 0.18.3

If a saved library cannot be read, AirCiller now keeps its data and offers recovery instead of clearing the list.

- Open the recovery notice in the library to restore a dated copy or explicitly start the affected list empty. Playlist, Recents and seasons are recovered separately; original movies are unchanged.
- Adding a file already in Playlist now explains that there is nothing new to add.
- Importing files alongside a season folder now includes both in the added-file count.

Recovery copies are saved at startup or explicit refresh, not continuously. A restored copy may lack more recent progress. Copies have a fixed storage limit; oversized or unreadable archives require manual inspection.

Formats and playback engines are unchanged.
[Recovery details and checks](https://github.com/carlosciller/AirCiller/blob/v0.18.3/Docs/LIBRARY_RELIABILITY_REVIEW.md).
